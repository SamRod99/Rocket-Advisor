# Rocket Advisor : Brave extension

Les dejare las intrucciones de como correr correctamente el proyecto


## Instalacion

Dentro de visual studio ejecuten el siguiente comando para instalar flask

```bash
  pip install flask
```
Una vez instalado, abrir el archvivo app.py y ejecutar

```bash
  cd backend
```  
```bash
  python app.py
```
Copiar url que te dara la consola, y si aparece el mensaje "el back funciona", ya esta listo para cargar la extension en brave.

En brave carga la carpeta "extension"

Puedes abrir un url que este dentro del dataset para comprar el funcionamiento.
